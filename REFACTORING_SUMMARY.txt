核心 API 变更示例
================================================================================

旧 API (路径参数):

新 API (查询参数):
  GET /api/k8s/pod?clusterId=xxx&namespace=default&name=pod-1

================================================================================
客户端迁移
================================================================================

Go 示例:
  params := url.Values{}
  params.Add("clusterId", "cluster-123")
  params.Add("namespace", "default")
  params.Add("name", "my-pod")
  url := "/api/k8s/pod?" + params.Encode()

Python 示例:
  from urllib.parse import urlencode
  params = {
      "clusterId": "cluster-123",
      "namespace": "default",
      "name": "my-pod"
  }
  url = f"/api/k8s/pod?{urlencode(params)}"

JavaScript 示例:
  const params = new URLSearchParams({
    clusterId: 'cluster-123',
    namespace: 'default',
    name: 'my-pod'
  });
  const url = `/api/k8s/pod?${params}`;
